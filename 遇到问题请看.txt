================================================================================
                        【macOS 系统首次使用必看说明】
================================================================================
1. 启动方式：
   双击文件夹内的【启动鸿蒙工具箱.command】即可直接调用 Mac「终端」运行。
   若连接异常无响应，可双击【工具箱无效运行这个.command】重置 ADB 服务。

2. 若通过网页 ZIP 或 Windows U 盘拷贝到 Mac 后提示“没有权限打开”：
   只需在 Mac 上打开「终端 (Terminal)」，执行以下命令（仅需一次）：
   cd /path/to/HarmonyOS-Toolbox-macOS
   chmod +x *.command adb && xattr -cr .

3. Mac 连接华为/荣耀手机说明：
   macOS 免装驱动！手机开启「开发者选项 -> USB 调试」并插上数据线（注意选“传输文件”），
   在手机端勾选「始终允许使用这台计算机进行调试」并确定，即可自动进入主菜单。

原版操作参考视频（B站 @一只靓仔琦）：

================================================================================
                          【常见 ADB 报错排查】
================================================================================
1. 提示 more than one device and emulator：
   当前连接了多个 ADB 设备（例如同时开了安卓模拟器），请到【功能模式 (m5)】断开
   或关闭模拟器的 ADB 后重试。

2. 提示 Failure [not installed for 0]：
   手机当前系统里没有该包名的 App，所以无需卸载，直接忽略即可。

3. 提示 device not found：
   设备未连接成功或数据线仅支持充电，请确认数据线支持数据传输且已开启 USB 调试。

4. 提示 device unauthorized：
   手机未授权调试。请拔掉数据线重新插入，留意手机屏幕弹出的授权框并点击“确定”；
   若仍不弹窗，可在手机“开发者选项”中点击“撤销 USB 调试授权”后再重连。


================================================================================
                            【常见问题说明】
================================================================================
1. 手机 ROM 中本就没有的应用无法通过本工具装回（需前往应用市场下载），只能装回原本
   内置过的系统应用。
2. 操作符号说明：负号（-）代表卸载或开启，加号（+）代表装回或关闭。
3. 本工具通过标准 ADB 接口运行，不会损坏硬件，但高危操作（如清理缓存、卸载输入法等）
   前仍请注意备份重要数据。
4. 提示“服务请求失败”通常是因为卸载了相关系统服务，重启手机后过一段时间一般不再提醒；
   若持续提醒，用对应 + 代码装回即可。
5. 已卸载的内置应用均可通过对应 + 代码或【定制模式 (m2)】中的 000 命令一键装回。
6. 个别应用无法卸载（如云空间、健康使用手机、华为桌面、手机管家等）属于系统级保护，
   属正常现象。
7. 操作完成后可放心关闭手机“USB 调试”或“开发者选项”，不会影响已经完成的卸载与设置。
